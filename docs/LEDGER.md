# Findings ledger -- live rows

The LIVE rows of the F-series findings ledger: every row whose State does not
begin `CLOSED`, the State read by its leading member as the legend below defines
it. Category C, Live -- continuously mutable; its integrity is the
register's two-plane law ([FRAMEWORK](/docs/governance/FRAMEWORK.md) section 14)
and not a version number. The ledger was seeded on 2026-06-11 and lived in
[ROADMAP](/docs/ROADMAP.md) until 2026-11-22, when its rows moved here and to
[LEDGER_ARCHIVE](/docs/LEDGER_ARCHIVE.md) byte-identically; the roadmap and its
phase history stayed in ROADMAP.

A ROW IS READ WHOLE. Every dated append inside a row is evidence, and a cell
quoted without the appends beneath it is a partial reading of the row.

THE ROW FORM is five cells on ONE physical line, ending in a closing pipe:
`| F-# | Finding | Severity | State | Resolution / owner |`. A pipe inside a cell
takes a leading backslash; a code span does not protect it. The G-ROWFORM gate
([FRAMEWORK](/docs/governance/FRAMEWORK.md) section 14.5) reads the table from
its header row and holds this document, and the archive, to that form. Rows are
kept in ASCENDING ID ORDER and are never re-sorted, re-numbered or re-wrapped.

A NEW ID IS MINTED FROM THE TAIL: the maximum id over BOTH this document and
`docs/LEDGER_ARCHIVE.md`, plus one -- never the neighbouring row's id plus one.
The maximum may stand in either document and moves between them: the row that
carries it closes, relocates to the archive, and is still the maximum. Measuring
one document alone mints an id that is already spent.

CLOSING A ROW is the State transition PLUS the relocation of the row to
`docs/LEDGER_ARCHIVE.md`, both in the SAME commit; the resolving commit hash is
written into the resolution cell, and that hash is the canonical closure pointer.
A row that has transitioned without moving leaves the two documents disagreeing
about where it belongs.

One row per finding; a finding lands at the closure that surfaces it, never
chat-only ([METHODOLOGY](/docs/methodology/METHODOLOGY.md) 12.9 (d)). No count
of rows, severities or states is written into this legend: a count goes stale
the moment a row is added.

The vocabulary below is declared once, for BOTH documents; the archive carries
no legend of its own.

Severity: S0 critical / S1 high / S2 medium / S3 low / S4 latent (a measured defect with no live instance) / N note.
State: OPEN / CLOSED / ACCEPTED-NO-ACTION. THE STATE CELL IS READ BY ITS LEADING MEMBER, with emphasis and a leading glyph stripped, never by equality; a member may carry a trailing qualifier in parentheses, as `OPEN (planned)` does, and the qualifier is not a new member. Every member is declared here whether or not a row currently carries it.
